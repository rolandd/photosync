## 2026-10-25 - Dynamic gauge colors
**Learning:** Hardcoded progress bar colors (like always using Cyan) fail to convey the system's overall health state to the user at a glance, reducing situational awareness.
**Action:** Always link the primary progress indicator's color to the current operational status (e.g., Red for errors, Yellow for warnings, Green for success, Cyan for active) so users immediately recognize when attention is needed.
